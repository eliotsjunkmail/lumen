# Snaptrack

Camera AR video field. Name a clip, pin it to GPS, and see it again within 25 feet from any direction.

## Open locally

```bash
npx --yes serve .
```

Allow camera, motion, and location.

## Use

1. Open lens
2. Add a video
3. Give it a name
4. It’s pinned where you’re aiming
5. Walk within 25 ft and aim from any side to watch
6. Tap × on your uploads to delete
